# 학습문서

이 폴더는 프로젝트 기본 설명 문서와 별개로, 작업 중 새로 정리한 학습용 문서를 주제별로 모아두는 위치다.

## 폴더 구조
- `배포와인프라/`: 배포 절차, 인프라 구성, 운영 순서, CI/CD 관련 학습 문서
- `웹네트워크/`: HTTP, HTTPS, 쿠키, CORS, 프록시, WebSocket 등 웹 네트워크 관련 학습 문서
- `진행과정/`: 실제로 어떤 방향으로 진행했고 어디까지 적용했는지 기록하는 진행 문서

## 정리 원칙
- 사용자가 "학습 문서", "정리 문서", "개념 문서" 성격으로 만들어 달라고 한 파일은 우선 이 폴더 아래에 둔다.
- 문서는 가능한 한 주제별 하위 폴더에 배치한다.
- 사용자가 실제 진행 상태나 적용 이력을 정리하도록 한 문서는 `진행과정/` 아래에 둔다.
- 프로젝트의 실제 동작 기준은 여전히 코드와 설정 파일이며, 학습 문서는 이해를 돕는 참조 자료로 사용한다.

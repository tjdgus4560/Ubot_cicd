# 진행과정

이 폴더는 학습용 개념 문서와 별개로, 프로젝트를 실제로 어떤 방향으로 진행했고 어디까지 적용했는지를 기록하는 문서를 모아두는 위치다.

## 목적
- 현재 진행 상태를 나중에 다시 확인할 수 있게 한다.
- "무엇을 공부했는지"와 "무엇을 실제로 적용했는지"를 구분해서 남긴다.
- 다음 작업자가 지금 단계와 다음 단계의 연결을 빠르게 이해할 수 있게 한다.

## 권장 기록 내용
- 작업 날짜
- 진행한 작업
- 실제로 적용한 내용
- 아직 적용하지 않은 내용
- 막혔던 점 또는 주의점
- 다음에 이어서 할 작업

## 권장 운영 방식
- 큰 작업을 하나 마칠 때마다 진행 문서를 갱신한다.
- 새 문서를 만들거나 기존 진행 문서를 이어서 업데이트해도 된다.
- 진행 문서는 "계획"보다 "실제로 한 것"을 중심으로 적는다.

## 예시 파일명
- `2026-04-06_배포진행상태.md`
- `docker-compose_적용기록.md`
- `nginx_ssl_진행메모.md`
